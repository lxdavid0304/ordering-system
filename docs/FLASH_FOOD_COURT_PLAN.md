# Costco 快閃熱食部開團功能規劃書

更新日期：2026-07-26  
定位：針對「當天採買、限時收單、到指定地點取餐」的熱食部活動；不包含分購、拆分大包裝或一般湊單。

## 1. 功能目標

讓管理員用一個活動頁快速開團，例如「7/30 午餐熱食快閃團」，設定開團時間、截止時間與取貨時段；會員只需選擇品項與數量，系統即時計算預估金額。

每一件商品均固定加收 **$20 運費**：

`會員預估單價 = 熱食部現場價 + $20`

例如熱狗堡套餐現場價 $50，會員頁面顯示「現場價 $50 + 運費 $20 = 預估 $70」。費用拆開顯示，避免讓使用者誤以為商品被任意加價。

> 本功能為限時代購，不保證現場一定有貨；實際售完、停售或價格調整時，由管理員在活動中標記並通知。

## 3. 管理員可自行設定的內容

建立活動時提供單一頁面的設定表單：

| 設定 | 說明 |
| --- | --- |
| 活動名稱 | 例如「7/30（三）午餐熱食快閃團」 |
| 開團時間 | 日期＋時間；到時間自動開放下單 |
| 收單截止 | 日期＋時間；到時間自動鎖單，不再接受修改 |
| 預計採買時間 | 供管理員排程與會員判斷新鮮度 |
| 取貨地點／時段 | 例如「明德樓大廳，12:20–12:40」 |
| 本次菜單 | 從上表指定品項勾選，調整當次現場價；披薩可填寫口味備註 |
| 每件運費 | 預設且建議鎖定為 $20；若日後需調整，須在開團前設定 |
| 每人／每品上限 | 例如每人最多 2 份、整盒披薩最多 1 盒 |
| 活動說明 | 取餐提醒、過敏原／保存提醒、逾時規則 |

快閃熱食表單僅限管理員建立、編輯、開團、鎖單與處理缺貨；一般會員只可瀏覽已開放活動並提交自己的選購內容。採買門市不設為活動欄位或會員選項。

## 4. 活動狀態與自動流程

```text
草稿 → 已排程 → 開放下單 → 已截止／鎖單 → 採買中 → 可取餐 → 已結束
                         └────────────────────────────→ 已取消
```

- **草稿**：只有管理員看得到，可反覆編輯。
- **已排程**：已設定開團時間；尚未開放會員下單。
- **開放下單**：會員可加選、修改數量；頁面顯示倒數。
- **已截止／鎖單**：保留訂購明細，不能再加購或修改。
- **採買中**：管理員已出發／正在採買；可逐項標示「已買到／售完」。
- **可取餐**：發送取貨提醒；會員可查看自己的明細與應付金額。
- **已結束／已取消**：活動封存，供會員回顧；取消時必須填寫原因。

系統檢查：截止時間必須晚於開團時間，且建議至少早於預計採買時間 30 分鐘；取貨時段不得早於預計採買時間。

## 5. 會員操作體驗

1. 在「快閃熱食」入口看到目前開放中的活動卡：截止倒數、取貨時間與取貨地點。
2. 點進活動後只顯示本次已開放的菜單；每個商品顯示現場價、$20 運費、預估單價與數量控制。
3. 底部固定小計：`商品現場價小計`、`運費小計`、`預估總額`，避免與一般採買清單的計費邏輯混淆。
4. 送出後取得「本次快閃訂單」與取貨碼；截止前可自行調整或取消。
5. 採買完成後，如遇缺貨或價格異動，會員會收到 LINE／站內通知，並看到處理結果。

甜點、咖啡、汽水等品項加上「建議取餐時間」標籤；不提供跨時段保溫／保冷承諾。

## 6. 管理員採買與例外處理

- 鎖單後可下載或在手機上查看「依品項彙總」的採買清單，例如熱狗堡 12 份、起司披薩單片 8 片。
- 每個品項可標記：`已買到`、`部分缺貨`、`已售完`、`價格異動`。
- 若部分缺貨，可個別勾選受影響會員；系統將該商品自應付總額扣除，不影響同筆訂單的其他商品。
- 若現場價格不同，管理員需輸入實際現場價與說明，系統保留原報價、調整前後差額與通知紀錄。
- 已鎖單後禁止直接覆寫會員選擇；取消或價格調整都必須留下原因與時間。

## 7. 資料與計價設計

建議新增獨立的活動資料，而不要把快閃活動硬塞進一般商品目錄：

| 資料 | 核心欄位 |
| --- | --- |
| `flash_food_campaigns` | 名稱、`open_at`、`deadline_at`、`purchase_at`、取貨資訊、狀態、每件運費預設 $20 |
| `flash_food_campaign_items` | 活動品項快照、現場價、每件運費、上限、是否季節限定、可售狀態 |
| `flash_food_selections` | 會員、活動、品項快照、數量、送出時的現場價與運費、處理狀態 |
| `flash_food_adjustments` | 缺貨／價格異動／取消原因、調整金額、管理員、通知狀態 |

重要原則：會員送出時，名稱、現場價與每件 $20 運費都必須寫入訂單快照。後台後續修改菜單，不得回頭改變已送出訂單的金額。

若沿用目前訂單主表，快閃訂單應標記 `source = flash_food` 或連結 `flash_food_campaign_id`，並避免再套用一般商品的額外運費規則，以防重複加收。

## 8. 權限、提醒與公告文案

- 僅登入會員可下單；活動頁清楚顯示「限本次收單時間內」。
- LINE／站內提醒節點：開團、截止前 30 分鐘、鎖單、可取餐、缺貨／價格異動、活動取消。
- 預設公告：
  - 「今天想吃什麼？選好就加入這一團，時間到我們一起幫你帶回來。」
  - 「熱食現做、取餐時間有限，請在指定時段到取貨點領取。」
  - 「現場品項可能售完；若無法購得，該品項不計費並會通知你。」

## 9. 分期實作建議

### 第 1 期：可用的快閃開團

- 後台建立／排程／截止活動。
- 菜單勾選、現場價設定、每件固定 $20。
- 會員選購、倒數、鎖單與個人明細。
- 管理員品項彙總清單與售完標記。

### 第 2 期：減少管理負擔

- LINE 自動提醒與缺貨通知。
- 實際價格調整與差額紀錄。
- 取貨碼／會員核銷。
- 常用活動模板，例如「午餐快閃」「週末披薩團」。

### 第 3 期：營運分析

- 每次活動的訂購人數、熱門品項、售完率與取消率。
- 依時段比較需求，協助決定下次菜單與截止時間。

## 10. 驗收條件

1. 管理員可設定任意未來的開團日、開團時間與截止日、截止時間。
2. 系統到開團時間才開放，到截止時間自動鎖單。
3. 每項會員明細都清楚顯示「現場價 + $20 運費」，總額正確依數量計算。
4. 後台可在不影響其他商品的前提下處理缺貨與價格調整。
5. 已送出訂單保留原始價格快照；後台改菜單不影響舊訂單。
6. 一般採買清單與快閃熱食活動的運費不會重複計算。

## 11. 上線前需確認的營運規則

- $20 是「每一份／每一件」計算；若同一會員買 2 份熱狗堡，運費為 $40。這份規劃依目前需求採此規則。
- 飲料等不耐久放品項的逾時未取處理方式。
- 現場售完時採「自動取消不計費」或「允許同價替代品」；建議首版只採自動取消，避免未經同意換品。
- 快閃團是否沿用既有付款門檻與收款方式；建議先沿用目前規則，待活動量增加再獨立設定。
